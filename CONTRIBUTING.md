# Contributing questions to the open UTME bank

Thank you! Every question you add helps students preparing for JAMB, and your GitHub username is shown on every question you write.

**Not comfortable with GitHub or JSON?** Use the [Suggest questions form](https://github.com/mb1720827-ui/exampal/issues/new?template=suggest-questions.yml) and type them in plain English. A maintainer will add them and credit you.

## The rules

1. **Original questions only.** Write your own. Don't copy from past JAMB papers, textbooks or websites: they're copyrighted, and copying puts the whole bank at risk.
2. **Follow the UTME syllabus.** Use a topic from `bank/subjects.json` for your subject.
3. **Exactly one correct option**, and three wrong options that a student might plausibly choose.
4. **The explanation teaches.** It says why the answer is right in a sentence or two, and it must **name the correct option** (the checks use this to catch an answer key pointing at the wrong letter).
5. **Plain, exam-style English.** Nigerian names and settings are welcome.

## Where questions live

```
bank/
  subjects.json              ← subjects and their syllabus topics
  english/
    spelling.json            ← one file per topic: a JSON array of questions
    synonyms.json
  mathematics/               ← maths is mostly generated by code (src/lib/math.ts);
                               add hand-written ones here as <topic>.json
```

Name the file after the topic in lowercase with hyphens: "Idioms and expressions" → `idioms-and-expressions.json`.

## Question format

```json
{
  "id": "eng-spe-09",
  "subject": "english",
  "topic": "Spelling",
  "stem": "Choose the correctly spelt word.",
  "options": ["recieve", "receive", "receeve", "riceive"],
  "answer": 1,
  "explanation": "The correct spelling is \"receive\": i before e, except after c.",
  "source": "authored",
  "author": "your-github-username"
}
```

| Field | What to put |
|---|---|
| `id` | Unique, lowercase with hyphens. Follow the file's pattern: subject, topic, number (`eng-spe-09`). |
| `subject` | The folder name (`english`). |
| `topic` | Exactly as written in `bank/subjects.json`. |
| `stem` | The question. |
| `options` | Exactly four different options. |
| `answer` | The position of the correct option: **0 = A, 1 = B, 2 = C, 3 = D**. Options are shuffled for students, so any position is fine. |
| `explanation` | Why the answer is right. Must contain the correct option's text. |
| `source` | Always `"authored"` for hand-written questions. `"generated"` is set by `npm run factory` for AI-drafted ones; review those pull requests like any other. |
| `author` | Your GitHub username (optional) for credit in the app. |

## Check your work

```bash
npm install
npm run check
```

You'll either see `✓ Question bank OK` or a list of problems in plain words, for example:

```
bank/english/spelling.json › eng-spe-09
  the explanation must mention the correct option ("receive"). If it doesn't, the "answer" index may point at the wrong option.
```

The same checks run automatically on your pull request.

## Adding a new subject

Physics, Chemistry, Biology and others are very welcome. In one pull request:

1. Add the subject to `bank/subjects.json` with its topics copied from the **official JAMB UTME syllabus** for that subject.
2. Create `bank/<subject-id>/` with at least 20 questions across several topics.

The app shows a subject as soon as it has questions. No code changes are needed.

## Fixing a mistake

Found a wrong answer or an unclear question? Use **Report a mistake** under the question in the app, or [open an issue](https://github.com/mb1720827-ui/exampal/issues/new?template=report-mistake.yml), or fix it directly in a pull request.
